# Areen Cubs website

Editorial portfolio site for Areen Cubs, built with Next.js App Router, TypeScript, Tailwind CSS and Framer Motion.

## Routes

- `/` — studio overview
- `/work` and `/work/[project]` — portfolio and case studies
- `/expertise` — strategy, creative and production
- `/studio` — studio philosophy, process and team placeholders
- `/insights` and `/insights/[article]` — editorial index and articles
- `/start-a-project` — short project enquiry

## Content

Project and article content is centralized in `src/data`. Concept panels intentionally identify where approved campaign media, behind-the-scenes photography, team portraits, credits and documented results still need to be supplied.

## Development

```bash
npm install
npm run dev
```

Run `npm run lint` and `npm run build` before release.
